# DPMod3-2026

## ¿Qué hace este módulo?
Módulo 3 del proyecto PubTube - Dirección de Proyectos.

## Requisitos previos
- Docker Desktop instalado
- Git

## Cómo levantar el módulo
Clonar el repositorio y ejecutar:

    git clone https://github.com/NahuelCatrileo/DPMod3-2026.git
    cd DPMod3-2026
    cp .env.example .env
    docker compose up

## Cómo correr los tests
    docker compose run tests
